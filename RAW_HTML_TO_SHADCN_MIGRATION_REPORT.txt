COMPONENT MAPPING REFERENCE
===========================

Raw HTML               → shadcn/ui Component
<button type="button"> → <Button variant="default">
<button> (link style)  → <Button variant="link">
<button> (outline)     → <Button variant="outline">
<button> (ghost)       → <Button variant="ghost">
<input type="text">    → <Input>
<input type="checkbox">→ <Checkbox>
<input type="radio">   → <RadioGroup> or <ToggleGroup>
<select>              → <Select>
<label>               → <Label>
Accordion (custom)    → <Accordion>
LinkContainer         → React Router <Link>

feedback_forms

- id, name (internal name), description (internal desc), header_title (default Give Feedback), header_subtitle, is_standalone (i.e. not attached to an event, date or slot), allow_multiple_responses (could user submit to this form more than once), is_active, created_at, updated_at

feedback_forms_questions

- id, feedback_form_id, display_order (this could be one of many questions in this feedback_form), star_question (if exists, show star selection), tag_prompt (if exists, show tag section), is_tag_multi_select, comment_placeholder (if exists, show comment section), is_active, created_at, updated_at

feedback_forms_questions_tags

- id, feedback_form_question_id, tag_text, display_order, is_active, created_at, updated_at

feedback_forms_assignments

**this table allows us to assign a form to a specific event, date or slot (optionally)

- id, feedback_form_id, event_id (nullable), event_date_id (nullable), event_slot_id (nullable), is_active, created_at, updated_at

feedback_sessions

** this table allows us to track (and resume) user sessions for a given form

- id, feedback_form_id, user_id, event_id (nullable), event_date_id (nullable), event_slot_id (nullable), created_at, updated_at, (completed_at? nullable)

feedback_responses

- id, feedback_session_id, feedback_form_question_id, star_rating (nullable, 1-5), comment_text (nullable), created_at

feedback_responses_tags

- id, feedback_response_id, feedback_form_question_tag_id, created_at
